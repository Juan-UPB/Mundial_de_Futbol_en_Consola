## Grupos asignados

* 🇨🇮 Costa de Marfil
* 🇵🇦 Panamá
* 🇮🇶 Irak
* 🇸🇪 Suecia

## Descripción

Este proyecto tiene como objetivo desarrollar un programa en Java relacionado con un Mundial de Fútbol, aplicando los conceptos de arreglos y matrices vistos en clase.

## Objetivos

* Aplicar arreglos y matrices.
* Trabajar con información de equipos y países.
* Desarrollar un programa interactivo en consola.
* Aplicar archivos de texto y ASCII Art.

## Paso 1: Banderas

### Descripción

Se implementará la representación de las banderas de los cuatro países asignados utilizando matrices y diferentes factores de escala.

### Tamaños

* Grande
* Mediano
* Pequeño
* Ícono

## Paso 2: Tabla de posiciones

Se construirá una matriz con los 48 equipos del Mundial y sus estadísticas:

**PJ, PG, PE, PP, GF, GC, DG, TA, TR y Pts.**

La tabla podrá actualizarse y se mostrará mediante paginación.

## Paso 3: Fixture de partidos

Se utilizarán arreglos y matrices para organizar los partidos, fechas y horarios del Mundial.

El usuario podrá consultar los partidos de cada grupo y la información de un partido específico.

## Paso 4: Colaboración

Los datos del Mundial se almacenarán en archivos **TXT** para facilitar su intercambio entre los equipos.

También se implementará un menú utilizando **ASCII Art**.

## Paso 5: Información de países

El programa permitirá consultar información de los países, como:

* Capital
* Jugadores principales
* Apariciones en Mundiales
* Bandera

## Tecnologías utilizadas

* Java
* Arreglos y matrices
* Archivos TXT
* ASCII Art
* GitHub

## Ejecución

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en Java.
3. Ejecutar el programa.
4. Seguir las opciones del menú.

## Conclusión

El proyecto permitirá aplicar los conocimientos de arreglos y matrices mediante el desarrollo de una aplicación de consola relacionada con un Mundial de Fútbol.
